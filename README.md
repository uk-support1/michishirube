# みちしるべ

**自分にも、できることがある。**

やりたいことを、小さな一歩に分けて、できたら消していく。ゴールへの階段を、自分のペースで登っていくための、スマホ向けのWebアプリです。点数も、順位もありません。うまくいかない日や、予定が変わる日も、大丈夫です。

## 使い方

- ブラウザで、公開されているアドレスを開くだけで、使えます（登録やログインは、要りません）。
- **iPhone：** 先に、「ホーム画面に追加」してから、そのアイコンから開いて、はじめてください（Safariの「共有」ボタン → 「ホーム画面に追加」）。追加の前に書いた記録は、追加したアプリには引き継がれません。
- **Android：** Chromeで開くと、「インストール」の案内が出ます。
- **パソコン：** ブラウザで、そのまま使えます。

## 記録について

- 記録は、あなたの端末の中（ブラウザの保存領域）にだけ保存されます。外には送られません。
- ブラウザのデータを消すと、記録も消えます。「これまでの記録」の画面にある、「すべての記録をコピー」で、ときどき控えを残しておくと安心です。
